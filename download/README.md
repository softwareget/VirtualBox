# Virtual Box

> 免费，轻量级的虚拟化软件。

## 下载

**Windows（64位）**：[点击下载Virtual Box 7.0 for Windows](https://www.virtualbox.org/wiki/Downloads/)

**Mac（Intel芯片）**：[点击下载Virtual Box 7.0 for MacOS Intel](https://www.virtualbox.org/wiki/Downloads/)

**Mac（ARM）**：[点击下载Virtual Box 7.0 for MacOS（ARM）](https://www.virtualbox.org/wiki/Downloads/)

## 教程

**1. 打开安装包**

  完成后，双击运行.exe（Windows）或.dmg（MacOS）文件。

  > 提示：如果Windows用户弹出“账户控制”提示，请点击“**是**”

**2. 安装过程**

  安装程序是英文的，但不用担心。只需要一直点击“Next”或“Install”就可。（默认设置很完美）
  
**3. 重启电脑**

  安装完成后，**建议**重启一下电脑，使配置生效。

## 快速上手（有很多进步空间）

### 创建虚拟机

  1. 打开软件，点击**New，新建**按钮。
  2. 输入名字（比如：MyFirstVM00）
  3. 挂载虚拟机**系统镜像**
  4. 点击“OK”或“完成”

### 使用虚拟机

  双击虚拟机名称，即可使用虚拟机！恭喜！

## 常见问题（Q & A）

  **Q：安装好之后，为什么鼠标在虚拟机里出不来？**
  **A：按下键盘右边的“Ctrl”键，即可释放鼠标。**

  **Q：我的虚拟机好慢！**
  **A：请在创建虚拟机的时候取消“启用3D加速”。**
